## スタンプの同期

```mermaid
sequenceDiagram
  actor A as みちゃ
  participant S as 家事ポン！
  actor B as よちゃ（カードを開いている）

  A->>S: マスを押す
  S-->>A: スタンプが押される
  S-->>B: すぐに同じスタンプが出る

  Note over A,S: 電波が無いとき
  A->>S: マスを押す
  S-->>A: エラーを出す（溜めて後で送ることはしない）
```
